# Swept Frequency Acoustic Interferometry (SFAI) Bode Data Processing and Peak Analysis

This workflow processes frequency-domain magnitude data collected using the Bode Analyzer for SFAI analysis. The notebooks are intended to be run sequentially:

1. `step1_column_seperator.ipynb` – separates a combined Bode dataset into individual frequency–magnitude files.
2. `step2_gaussian_convolution.ipynb` – smooths and interpolates each magnitude curve.
3. `step3_peaks_halfwidth.ipynb` – detects peaks within selected frequency regions and calculates peak widths.

## Important Data Requirements

Before running Step 1, the Bode measurements must be collected using a consistent experimental and frequency-sweep configuration.

All magnitude datasets placed in the same input file must:

* Have been collected using the same Bode/SFAI testing setup and measurement configuration.
* Use the same frequency range.
* Use the same frequency sampling/sweep settings so that the frequency points correspond between measurements.
* Contain the same number of frequency points.
* Be aligned so that each row represents the same frequency for every magnitude measurement.

This is required because Step 1 uses **one shared frequency column for all magnitude columns**. The code assumes that every magnitude value in a given row was measured at the frequency listed in the first column of that same row.

For example, the input should have the following numerical structure:

```text
Frequency    Mag1    Mag2    Mag3    ...    MagN
f1           M1,1    M2,1    M3,1           MN,1
f2           M1,2    M2,2    M3,2           MN,2
f3           M1,3    M2,3    M3,3           MN,3
...          ...     ...     ...            ...
```

In the actual file supplied to the notebook, the data should be stored as a numerical table compatible with `numpy.loadtxt`. If column labels are present, they must be removed or otherwise formatted so that they do not interfere with loading the numerical data.

Magnitude datasets obtained using different frequency ranges, frequency spacing, numbers of sweep points, or substantially different Bode measurement configurations should **not** simply be placed into the same Step 1 input table.

## Step 1 – Separate Magnitude Columns

`step1_column_seperator.ipynb`

Step 1 takes a combined numerical file arranged as:

```text
Frequency | Magnitude 1 | Magnitude 2 | ... | Magnitude N
```

The first column is treated as the common frequency axis. Each remaining column is treated as an independent magnitude measurement.

The notebook creates a separate two-column `.dat` file for every magnitude column:

```text
Frequency | Magnitude
```

For example, an input file named:

```text
Sample.dat
```

containing three magnitude columns will produce:

```text
Sample_col1.dat
Sample_col2.dat
Sample_col3.dat
```

Each output file retains the original shared frequency values and one corresponding magnitude dataset.

These files become the inputs for Step 2.

## Step 2 – Gaussian Smoothing and Interpolation

`step2_gaussian_convolution.ipynb`

Step 2 batch-processes the individual `.dat` files generated in Step 1.

For each frequency–magnitude dataset, the processing sequence is:

```text
Original magnitude data
        ↓
Gaussian smoothing
        ↓
Magnitude scaling, if specified
        ↓
Cubic-spline interpolation
        ↓
Peak identification
```

The Gaussian filter smooths local variations in the measured magnitude response. The default Gaussian standard deviation is:

```python
std_dev = 2
```

After smoothing, a cubic spline is constructed and evaluated on a denser frequency axis. By default, the interpolated response contains:

```python
num_interp_points = 10000
```

points spanning the original minimum-to-maximum frequency range.

The interpolation does **not** represent additional experimental measurements. It is a mathematical estimate of the response between the experimentally measured frequency points and provides a finer frequency grid for subsequent peak analysis.

The notebook saves each processed dataset using the naming convention:

```text
OriginalFile_convolved.dat
```

For example:

```text
Sample_col1.dat
```

becomes:

```text
Sample_col1_convolved.dat
```

Plots of the original and processed responses are also generated so that the smoothing and detected peak structure can be visually inspected.

## Step 3 – Peak Detection and Half-Width Analysis

`step3_peaks_halfwidth.ipynb`

Step 3 performs peak analysis on the convolved/interpolated files generated by Step 2.

The user defines:

* Which magnitude columns should be analyzed together.
* The frequency range or ranges of interest for each group.

Within each selected frequency range, the code determines the maximum magnitude and establishes relative thresholds for peak detection:

* Minimum peak height = 10% of the maximum magnitude in the selected region.
* Minimum peak prominence = 3% of the maximum magnitude in the selected region.

Detected peaks are then analyzed using `scipy.signal.peak_widths` with:

```python
rel_height = 0.5
```

The left and right crossing locations returned by the peak-width calculation are converted from array-index positions into frequency values. The reported peak width is therefore expressed in Hz:

```text
Width = Right Crossing Frequency − Left Crossing Frequency
```

The analysis outputs the detected peak frequencies and corresponding widths for each selected frequency region.

Results are saved as tab-delimited files containing:

```text
Range_Index    Peak_Frequency    Width
```

The notebook also plots grouped magnitude responses with the detected peak locations overlaid. These plots provide an important visual quality-control step to verify that the algorithm is identifying the intended resonance peaks.

## Overall Workflow

```text
Bode/SFAI measurements
        ↓
Measurements collected using matching sweep settings
        ↓
Combined file:
Frequency | Mag1 | Mag2 | ... | MagN
        ↓
STEP 1
Separate magnitude columns
        ↓
Frequency | Magnitude files
        ↓
STEP 2
Gaussian smoothing + cubic-spline interpolation
        ↓
Convolved/interpolated files
        ↓
STEP 3
Select frequency regions
        ↓
Peak detection + half-width calculation
        ↓
Peak frequency and width results
```

### Reproducibility Note

The consistency of the original Bode measurements is important for meaningful comparison between magnitude curves. When comparing measurements within an experimental set, the same Bode measurement configuration, frequency limits, sweep resolution, and experimental setup should be maintained whenever applicable. This ensures that corresponding rows and frequency locations represent directly comparable measurements throughout the processing workflow.
